## 播放与素材

- `js/voice-config.js`：唯一语言目录、输入白名单、旧设置迁移和座位/性别到声线的映射。
- `js/voice-packs.js`：经完整校验的方言包登记；普通话继续使用原四个目录。
- `js/sound.js`：实际报牌、余牌提示、接风双方和逐家试听共用路由。四个对局通道与一个试听通道独立；修改某家设置只停止该家和试听。
- `audio/voice/dialect-manifest.json`：声线、性别、方言区域、台词、时长和逐段 SHA-256。每包涵盖统一词表的所有 ID，试听拼接实际报牌片段。
- `mobile/sw.js`：只缓存登记就绪的完整语音包，离线与在线使用同一路径，支持 GitHub Pages 仓库子目录。

粤语台词采用粤语表达；数字及牌型仍与游戏事件一一对应。其余方言采用服务区域声线或模型明确支持的方言合成，男女声为不同声线，无移调伪装。河南女声按用户要求采用原速 85% 的减速版，保留音调；其余维持各自原始语速。程序校验覆盖文件完整性和播放，口音自然度仍需母语使用者试听。逐包来源、许可与未采用的素材见 [方言来源核查](dialect-sources.md)。

## 开发时生成

原普通话素材使用本地 Qwen3-TTS，其既有生成方式与来源记录保持不变。粤语男女声和东北女声通过 `edge-tts` 调用公开可用的微软声线，音色名称和性别以服务返回目录及[微软语言与声线说明](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=tts)核对。`edge-tts` 只用于开发，不随游戏作为运行依赖；项目没有复制其实现代码。可用目录不代表所有 Azure 专用声线都能通过该入口调用。

```bash
GUANDAN_VOICE_PYTHON=/path/to/venv/bin/python \
GUANDAN_FFMPEG=/path/to/ffmpeg \
GUANDAN_FFPROBE=/path/to/ffprobe \
node tools/build-dialect-voices.cjs
```

旧四川男声 `zh-CN-sichuan-YunxiNeural` 通过公开网页导出长音频，导入器在拆分前检查 72 条台词恰好对应 71 个内部停顿。新版按用户偏好改用本地 Eric：

```bash
GUANDAN_VOICE_PYTHON=/path/to/isolated-venv/bin/python \
GUANDAN_VOICE_MODEL=/path/to/Qwen3-TTS-12Hz-1.7B-CustomVoice-4bit \
node tools/build-eric-sichuan.cjs
```

加 `--samples` 只生成独立小样，不安装。旧四家生成路径的普通话指令保持原样；仅为明确配置 `dialect` 的新角色启用本地方言指令。

普通话生成器可加 `--profile calm` 单独重制这套男声，合并原有清单并保留其他角色和方言，不必重复生成整套。

本地 VoxCPM2 的本轮方言来源均已被否定，配置已禁用。更换来源并通过试听后，才可启用相应配置；保留生成器用于开发。

```bash
GUANDAN_DIALECT_MODEL=/path/to/VoxCPM2-4bit \
GUANDAN_VOICE_PYTHON=/path/to/isolated-venv/bin/python \
GUANDAN_FFMPEG=/path/to/ffmpeg \
GUANDAN_FFPROBE=/path/to/ffprobe \
node tools/build-local-dialect-voices.cjs --profile 已启用的新来源
```

模型可使用 `tools/download-dialect-model.py 目标目录` 下载并逐文件核对官方 LFS SHA-256。生产配置在 `tools/local-dialect-voices.json`。四川女声两版均已否定；平实语气和时长限制没有解决方言真实性，因此禁用该配置，后续先换来源再验收短句。每条源 WAV 带参数哈希和生成版本，中断可恢复。`--samples` 只进入测试目录。已否定的沪语配置同样禁用，扬州配置移除，批量生成不会复用。

所有导入和生成方式共用 `tools/voice-pack-utils.cjs`，完整校验通过才安装并合并登记，重新生成一个来源不会删除另一来源的包。游玩时无需 Python、模型、API 密钥或联网。新增语言的素材必须先获得实际可用且允许使用的语音源，再扩展配置和整包生成；不要用修改标签、普通话重命名或移调代替方言与性别。
