# 手机横屏离线版

这是完整掼蛋项目中新增的手机入口。原电脑版保留在项目根目录的 `index.html`，手机入口为 `mobile/index.html`；首页版本号旁可以互相切换。

手机专用的横屏样式、旋转提示、桌面应用清单、图标和离线缓存放在本目录。两版共用根目录 `js/` 的规则、AI、状态机和界面逻辑，以及 `css/` 的基础牌桌样式；修改规则不需要维护两份副本。

请将**完整项目 / 完整发布目录**部署到 HTTPS 地址，然后在手机上打开 `/mobile/`。不要只上传本目录，否则共享的规则和界面资源会缺失。

首次打开等待「离线已就绪」，安卓可在 Chrome 中安装 / 添加到桌面，iPhone 可在 Safari 中点「分享 → 添加到主屏幕」。手机横屏游玩，转回竖屏会提示旋转并暂停当前对局。

手机离线缓存只缓存本版资源，作用域仅为 `mobile/`，不会把电脑版入口替换为手机版。电脑版仍可解压完整发布包后双击 `index.html` 离线运行。两版沿用原存档格式；在同一浏览器和同一来源下使用相同的本地进度，在不同设备或浏览器中分别保存。

完整安装与打包步骤见 [项目说明](../README.md)。
