# 手机横屏离线版

这是完整掼蛋项目中新增的手机入口。原电脑版保留在项目根目录的 `index.html`，手机入口为 `mobile/index.html`；首页版本号旁可以互相切换。

手机专用的横屏样式、旋转提示、桌面应用清单、图标和离线缓存放在本目录。两版共用根目录 `js/` 的规则、AI、状态机和界面逻辑，以及 `css/` 的基础牌桌样式；修改规则不需要维护两份副本。

牌桌按实际可视宽高自适应，不按手机型号限定：常规横屏保留整行手牌，自己的状态、出牌操作和手牌工具集中在底栏；窄屏或浏览器工具栏压缩高度后，出牌操作切换到手牌侧边。左右同时预留较大的屏幕安全边距，兼顾刘海、灵动岛及两种横屏方向；底部避开手势区域。平板横屏沿用同一布局。

中央有效牌放大并下移，与顶部对家保持间距；常规横屏将牌型说明和回合提示并排放在牌面上方。左右两家在本墩打出的牌保留到收墩，各家的状态显示实际牌型；中央只展示当前有效牌，避免把被压过的牌混为有效牌。

左右两家的倒计时放在手牌数量下方的固定状态行内，再次轮到该家时不会遮住仍在桌面的上一手牌。底部自己的状态也预留固定行高，过牌文字出现时不抬高手牌。可运行 `node test/browser/return-turn-clock.cjs` 检查不同尺寸下三张和五张炸弹被压过、回合再次轮到东西两家的场景。

同点数牌和理牌后的完整组合保持同一竖列，四至八张炸弹不会拆成几列。配牌保留真实点数并放在本组前方，例如三个 A 与红桃级牌组成四炸时不会拆开。叠牌间距随可用高度收紧；窗口特别矮或长炸弹放不下时，手牌区支持上下滑动并显示提示，为中央出牌区保留空间，仍可逐张选择和出牌。

选牌说明、配牌说明和出牌提示使用固定位置；窄屏的提示区域固定高度。提示出现、换行、切换或清空时，手牌、中央有效牌和操作按钮保持原位。可运行 `node test/browser/feedback-stability.cjs` 检查实际交互前后的坐标。

普通花色和大小王牌徽按整张牌的水平、垂直中心对齐；配牌与分组标记独立放置，不挤动主图案。手牌、中央有效牌和出牌记录使用一致的牌面图形。

自己出完后，底部自动切换为对家剩余手牌并标明「观战」，仍由对家电脑出牌；观战期间不能选牌、出牌或开启托管。对家出牌后实时更新，刷新继续也会恢复观战；对家出完即结束显示，下一副恢复自己的手牌。观战时记牌器扣除已看到的对家手牌；电脑决策仍只使用自身手牌与公开出牌信息。

开发时可运行 `node test/mobile-viewport.cjs` 和 `node test/browser/mobile-layout.cjs`。后者使用隔离的 Chrome 存储，覆盖多种手机 / 平板尺寸、安全区域、四家倒计时、叠牌、触屏选牌和辅助面板；浏览器模拟检查不能替代 iOS / Android 真机验收。

请将**完整项目 / 完整发布目录**部署到 HTTPS 地址，然后在手机上打开 `/mobile/`。不要只上传本目录，否则共享的规则和界面资源会缺失。

首次打开等待「离线已就绪」，安卓可在 Chrome 中安装 / 添加到桌面，iPhone 可在 Safari 中点「分享 → 添加到主屏幕」。手机横屏游玩，转回竖屏会提示旋转并暂停当前对局。

手机离线缓存只缓存本版资源，作用域仅为 `mobile/`，不会把电脑版入口替换为手机版。电脑版仍可解压完整发布包后双击 `index.html` 离线运行。两版沿用原存档格式；在同一浏览器和同一来源下使用相同的本地进度，在不同设备或浏览器中分别保存。

完整安装与打包步骤见 [项目说明](../README.md)。
