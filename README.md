# 单机掼蛋

四人单机掼蛋游戏：你与三名电脑玩家对局，对家组队。支持电脑和手机横屏游玩，无需登录，可离线运行。

## 在线游玩

- [电脑版](https://sidneypearson.github.io/guandan-web/)
- [手机横屏版](https://sidneypearson.github.io/guandan-web/mobile/)

## 主要功能

- 完整升级对局、快速一局，三档电脑难度。
- 提示、理牌、托管、记牌器和出牌记录。
- 电脑与托管共用 AI：完整动作枚举、手牌结构评估、公开信息记牌、队友配合和残局阻断；普通/困难模式通过独立未知手牌采样进行蒙特卡洛模拟，不读取其他玩家真实手牌。
- 搜索由 Web Worker 执行，超时回退规则策略；双击本地 HTML 也支持 Blob Worker。默认预算和配置方法见 [AI 系统说明](docs/ai-system.md)。
- 下家对手剩五张时加强五张收尾防范；多炸弹配少量散单时优先清散单，保留完整炸弹，同花顺也计入保护。必须拦截对手或自己能直接出完时保留例外。
- 回合倒计时、自动存档、本地战绩。
- 自己出完后自动观战对家手牌，实时跟随剩余牌更新；下一副恢复自己的手牌。
- 顺子连飞、三连对连锁、钢板合击，以及逐级增强的炸弹、四大天王特效。
- 四家可分别选择语言和性别，支持真实点数、炸弹张数、过牌和余牌提醒，可逐家试听或关闭。
- 原创常驻背景音乐，可单独开关和调节音量；报牌时自动压低，切到后台暂停，离线可播放。

## 离线使用

**电脑**：下载完整项目，打开根目录的 `index.html` 即可游玩。

**手机**：用 Safari 或 Chrome 打开手机版，首次联网等待「离线已就绪」。通过浏览器菜单添加到主屏幕，再从桌面图标启动并横屏游玩。微信内建议选择「在浏览器打开」。

中文语音随游戏内置，离线也能报牌。设置里的「声音」控制全部声音，「中文报牌」可单独关闭。出牌节奏固定为标准、对战特效固定为完整；可开启减少动效。托管跟随当前对局的电脑难度，无需单独选择。接风时由出完牌的队友招呼、接风方回应，使用各自声线。
设置中可分别选择你、东家、对家、西家的语言与男声/女声，逐家试听，自动保存。当前内置普通话、粤语、沪语男女声，以及河南女声、四川男声。粤语已通过用户试听；沪语晓彤女声、云哲男声和新版河南女声的小样通过后，已制作完整报牌包。河南男声、东北男女声以及四川女声、盐城阜宁话未通过的整包继续停用，扬州话保留选择。缺少合格完整素材的组合显示「待补充」，保留选择并暂停该家的报牌。语言、声线来源及当前可用情况见 [语音设置与素材](docs/voice-system.md)。
四家可以同时说话，下一家的报牌不会截断上一家；接风由双方各自选定的声线应答。默认普通话保留四位不同角色的报牌风格，播放时使用素材原本的语速和声调。
四家各有六种常规过牌台词和两种“要不起”类台词，按各自角色口吻随机轮换，避免连续重复；确实无牌可压时才会穿插“要不起”。普通牌压住对手时，多数只说“大你”“压上”“管上”中的一句，偶尔报具体牌，不再把两段连播。普通出牌后只剩一两张时，只提醒余牌数；领牌、跟队友牌和特殊牌型保留必要报牌。

背景音乐为原创《牌桌小调》，首次点按后以低音量循环播放，换局和打开菜单保持连续；报牌时自动压低，切换到后台时暂停。设置中的「背景音乐」和「音乐音量」会自动保存，声音总开关仍控制全部声音。可用 `python3 tools/build-music.py` 重新生成原曲，需要 NumPy 和 ffmpeg。

进度保存在当前设备的浏览器中；清除网站数据会删除存档。具体规则可在游戏内查看。

## 本地运行与打包

项目使用原生 HTML、CSS 和 JavaScript，无需安装运行依赖。

**macOS**：双击根目录的 `启动.command`，会启动本地服务并打开游戏。服务在后台运行，关闭启动终端后仍可访问；电脑重启后再双击一次即可。重复启动会复用已运行的服务。

也可在项目根目录手动启动（需保持终端运行）：

```bash
python3 -m http.server 8896 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8896/` 游玩电脑版，`http://127.0.0.1:8896/mobile/` 游玩手机版。固定使用同一地址可继续读取原有的浏览器存档。

生成包含两版的发布包：

```bash
node tools/build-dist.js
```

文件输出到 `dist/`。

普通话语音由开发时本地生成，游玩时只播放随包交付的 MP3。四家角色定义在 `tools/voice-characters.json`。重新生成需要 Apple Silicon、装有 `mlx-audio` 的 Python 环境和本地 Qwen3-TTS 1.7B CustomVoice MLX 模型：

```bash
GUANDAN_VOICE_PYTHON=/path/to/venv/bin/python \
GUANDAN_VOICE_MODEL=/path/to/local-model \
node tools/build-voices.cjs
```

全部录音生成并通过校验后才会替换游戏语音包；生成中断可利用本地缓存继续。

方言素材记录实际声线、来源、逐段哈希和试听反馈。粤语保留用户已通过的版本；沪语采用小样通过的晓彤女声和云哲男声，河南女声换用本轮通过的晓晓河南话模式，并按要求放慢到原语速的 85%，旧版仍被禁止恢复。四川男声保留 Eric，误用 Eric 的普通话男声已改为 Uncle_Fu；河南男声、东北男女声、四川女声及阜宁未通过的素材继续停用。文件完整与口音验收分别记录，设置中显示真实可用状态。生成命令、可用矩阵、素材许可及验证结果见 [语音设置与素材](docs/voice-system.md) 和 [方言来源核查](docs/dialect-sources.md)。

本轮方言素材扩充已按用户的复杂度取舍收尾，保留当前可用声线；其余组合保持不可用。
